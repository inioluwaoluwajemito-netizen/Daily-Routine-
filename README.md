# Daily-Routine-

> **DayGuide** — An intelligent, proactive daily routine and timetable app that acts as a personal day coach. Built with React Native & Expo (TypeScript) and powered by an offline-first SQLite database with smart local reminders.

---

- **[PRD.md](./PRD.md)**: Product Requirements Document with core problem statement, functional specifications (P0/P1/P2), and user stories.
- **[APP_ARCHITECTURE_AND_PLAN.md](./APP_ARCHITECTURE_AND_PLAN.md)**: System architecture diagrams, UX wireframes, and dynamic re-planning algorithms.
- **[TECH_STACK_AND_TOOLS.md](./TECH_STACK_AND_TOOLS.md)**: Technology stack evaluation, required tools, and APK build guidelines.

## 📱 Application Codebase

The mobile application is located in the [`dayguide/`](./dayguide/) directory.

### Quick Start (Wireless Mobile Preview)
```bash
cd dayguide
npm start
```
Scan the QR code with **Expo Go** on your Android phone to run the app instantly!
